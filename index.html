⚙️ How It Works

Base URL:
Append any configured path to the base URL to trigger a redirect.

Example: /google → https://www.google.com

Adding redirects: Edit redirects.json in the repo to add, remove, or modify redirect mappings.

Analytics: Set your GA4 Measurement ID in redirects.json under settings.googleAnalyticsId to track redirect usage.
